# Customer Segmentation & Purchase Behavior Dashboard

## Project Overview
This project focuses on customer behavior analysis and segmentation using Power BI. The dashboard provides insights into customer demographics, purchasing patterns, customer preferences, review ratings, and spending behavior through interactive visualizations.

## Objectives
- Analyze customer demographics and purchasing behavior
- Identify customer preferences and trends
- Visualize customer purchase patterns
- Understand customer segmentation for business insights

## Tools Used
- Power BI
- Data Analysis
- Data Visualization

## Dataset Features
The dataset includes:

- Customer ID
- Age
- Gender
- Purchase Amount (USD)
- Review Rating
- Previous Purchases
- Item Purchased
- Payment Method
- Shipping Type
- Category
- Season
- Subscription Status

## Dashboard Components

### KPI Cards
- Total Customers
- Total Purchase Amount
- Average Previous Purchases

### Visualizations
- Pie Chart: Customer Demographics
- Bar Chart: Customer Preference Analysis
- Funnel Chart: Review Rating by Category
- Area Chart: Purchase Amount by Shipping Type
